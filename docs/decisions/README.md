# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for Payflow.

ADRs document significant architectural decisions — what was decided, why, and what alternatives
were considered.

## Format

Each ADR is a numbered markdown file:

```
decisions/
├── ADR-001-database-choice.md
├── ADR-002-api-framework.md
└── ...
```

## Status

No decisions have been recorded yet.

ADRs will be created as implementation progresses and decisions are validated through the
first engineering loop.
